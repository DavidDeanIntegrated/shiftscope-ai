Freed

by Freed · getfreed.ai ↗

Self-serve AI scribe for individual clinicians with a Chrome extension that pushes notes into browser-based EHRs.

Key features (as described by vendor and sources)

  • Specialty-specific templates; unlimited notes on Core and above
  • Premier adds visit summaries, patient instructions/letters, EHR push and ICD-10/CPT coding
  • EHR Push via Chrome extension (Starter/Core limited to 5 lifetime transfers)
