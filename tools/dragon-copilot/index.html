Microsoft Dragon Copilot (formerly DAX Copilot)

by Microsoft (Nuance) · learn.microsoft.com ↗

Microsoft's ambient + dictation clinical assistant with an Emergency Department specialty output.

Key features (as described by vendor and sources)

  • Selecting 'Emergency Medicine' as primary specialty maps to an Emergency Department note output
  • ED guidance: speak MDM aloud as a narrative; timestamps and critical care minutes must be spoken to be captured
  • ED model updates for reduced repetition, billing-relevant elements and timestamp capture (release notes)
