# ShiftScope AI (v1)

A static, dependency-free directory of AI tools for emergency medicine, plus a stub for the weekly "What's new in ED AI" newsletter.

## Run locally
```bash
cd /workspace/shiftscope
node build.mjs                                     # builds to dist/
python3 -m http.server 4321 --directory dist       # open http://localhost:4321
node scripts/check-links.mjs                       # checks every internal link
```
Needs Node 18+ only. There are no npm dependencies.

## Edit content
- `data/tools.json` holds the tool listings. It's generated by `scripts/seed_tools.py`. Edit the Python file and re-run it, or edit the JSON directly.
- `data/categories.json` and `data/site.json` hold the categories and the ED review criteria.
- `src/pages/*.html` holds the methodology, submit, sponsor, about, newsletter and disclaimer copy.
- `src/assets/` holds the CSS, JS and favicon.
- The build fails if any tool has a non-null `physician_review` or `ratings`. That guard stops placeholder scores from shipping. When a real review exists, change the guard and the template together.

## Deploy (not done yet, needs the owner)
- **GitHub Pages:** push the repo, then set Settings → Pages → Source: GitHub Actions. `.github/workflows/deploy.yml` builds with `BASE=/shiftscope-ai/` for https://daviddeanintegrated.github.io/shiftscope-ai/.
- **Cloudflare Pages or Netlify:** build command `node build.mjs`, output directory `dist`.
- Set `SITE_URL=https://yourdomain` at build time to get canonical URLs and an absolute sitemap.
